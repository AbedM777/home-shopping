# קניות הבית

אפליקציית רשימת הקניות של הבית: רשימת ברירת מחדל לפי ספר המתכונים, רשימה לכל חודש, מיון לפי מחלקות בסופר, סימון בזמן אמת אצל כל בני הבית, והתראות עם מספר על האייקון כשמישהו מוסיף מוצרים.

- האפליקציה מתארחת ב-GitHub Pages ומותקנת למסך הבית מתוך Safari (שיתוף ← הוספה למסך הבית).
- הנתונים נשמרים ב-Firebase Firestore. הגישה אליהם דורשת את הקוד המשפחתי שבקישור (`#k=...`), והוא לא נשמר במאגר הזה.
- `notify/` הוא הקוד של שירות ההתראות (Cloud Run function בשם notify-new-items, europe-west1). הוא נערך ומועלה מתוך Google Cloud Console.
- `firestore.rules` הם כללי הגישה שמוגדרים ב-Firestore.
